Marketing-site teams rebuild hero, pricing and CTA sections often and need them on-brand each time. One-way Figma exports produce code nobody wants to maintain; BluePainter instead keeps the canvas and your existing TSX in sync through stable `id` attributes.

## Evaluation checklist

1. Do visual edits need to land in the real repo, as small diffs?
2. Do you need contrast, spacing and CTA policy enforced — not only code generated?
3. Is a designer–engineer pair going to use it together?
